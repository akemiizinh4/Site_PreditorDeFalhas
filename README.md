# Preditor de Falhas na Rede

**→ [akemiizinh4.github.io/Site_PreditorDeFalhas](https://akemiizinh4.github.io/Site_PreditorDeFalhas/)**

Página do projeto **Preditor de Falhas na Rede**, do Grupo 7 de Ciência da Computação do Centro Universitário Braz Cubas — Estrutura de Dados II, Profª Andrea Ono Sakai.

O projeto usa medições públicas de ping do RIPE Atlas para prever se a próxima medição de um caminho da internet será **OK**, **RISCO** ou **FALHA**, comparando cada caminho com o seu próprio normal. São 131 caminhos e 695.132 medições, com F1 macro de 0,7675 no teste.

O projeto completo, com os notebooks e a documentação, está em [GzTop1/Redes-Projeto](https://github.com/GzTop1/Redes-Projeto).
